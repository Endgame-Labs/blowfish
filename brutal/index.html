QUICKSTART

Dive in with two snippets.

Start blowfish locally with Docker Compose, then talk to it using the official turbopuffer SDK.

STEP 01 Start blowfish locally (bash) 
git clone https://github.com/endgame-labs/blowfish.git && cd blowfish
docker compose up --build --wait blowfish   # serves on 127.0.0.1:8000, auth off for local dev
STEP 02 Write & query with the official SDK (python) 
# pip install turbopuffer
import os
os.environ.pop("TURBOPUFFER_REGION", None)  # a region only applies to turbopuffer's own URLs
import turbopuffer
tpuf = turbopuffer.Turbopuffer(api_key="dev", base_url="http://127.0.0.1:8000")
ns = tpuf.namespace("hello")
ns.write(upsert_rows=[{"id": 1, "vector": [0.1, 0.2], "text": "hello, blowfish"}], distance_metric="cosine_distance")
print(ns.query(rank_by=("vector", "ANN", [0.1, 0.2]), top_k=1).rows)

FEATURES

Small binary. Big ocean energy.

Everything you need for fast vector and full-text search—without hauling around a second database.

{ }

SDK-compatible

Speaks the turbopuffer API natively. Keep the official Python, TypeScript, Go, Java, Ruby, and Rust SDKs unchanged—just point base_url at blowfish.

⬡

Your bucket is the database

Stores everything in any S3-compatible bucket (AWS S3, Cloudflare R2, MinIO, and SeaweedFS) or a local directory. No other database. Servers are stateless caches; run more copies to scale out.

⌕

Vector, BM25, hybrid, and filters

Approximate nearest neighbor (ANN) vector search, exact BM25 full-text search, hybrid queries, and structured filters—all built into one cohesive engine.

▲

Scales to 100M on one machine

Handles 100M documents comfortably on a single AWS node, and a 10M-document load fits on a 4 GB machine.

⚙

Single Rust binary

One self-contained Rust executable. No separate metadata store, no coordinator cluster, and no dependency soup to wrestle with.

♥

MIT licensed & honest

Open-source under the permissive MIT license. Light heads-up: blowfish is pre-1.0 (v0.1.13), so the storage format may still change.
