PRESS START

Quickstart in two moves

Boot blowfish locally with Docker Compose, then talk to it using the official turbopuffer SDK unchanged.

STEP 01 · BOOT BLOWFISH (BASH) 
git clone https://github.com/endgame-labs/blowfish.git && cd blowfish
docker compose up --build --wait blowfish   # serves on 127.0.0.1:8000, auth off for local dev
STEP 02 · QUERY WITH OFFICIAL SDK (PYTHON) 
# pip install turbopuffer
import os
os.environ.pop("TURBOPUFFER_REGION", None)  # a region only applies to turbopuffer's own URLs
import turbopuffer
tpuf = turbopuffer.Turbopuffer(api_key="dev", base_url="http://127.0.0.1:8000")
ns = tpuf.namespace("hello")
ns.write(upsert_rows=[{"id": 1, "vector": [0.1, 0.2], "text": "hello, blowfish"}], distance_metric="cosine_distance")
print(ns.query(rank_by=("vector", "ANN", [0.1, 0.2]), top_k=1).rows)

Prefer another language? The official turbopuffer SDKs for Python, TypeScript, Go, Java, Ruby, and Rust all work unchanged — just point base_url at blowfish!

POWER-UP SELECT

Everything in one cozy shell

No sprawling cluster to wrangle — just a spiky little Rust binary sitting happily in front of object storage.

SDK-compatible

Speaks the turbopuffer API natively. Drop in the official Python, TypeScript, Go, Java, Ruby, or Rust SDK without changing your query code.

Your bucket is the database

Stores everything in AWS S3, Cloudflare R2, MinIO, SeaweedFS, or a local directory. No other database — servers are stateless caches, so run more copies to scale out.

Vector, BM25, hybrid, and filters

Approximate nearest-neighbor (ANN) vector search, exact BM25 full-text search, hybrid ranking, and attribute filters all ship in the same engine.

Scales to 100M on one machine

Queries pull what they need straight from object storage and warm up local cache. Even a 10M-document load fits comfortably on a 4 GB machine.

Single Rust binary

One compiled Rust binary with zero sidecar databases, brokers, or coordination services to babysit at 3 a.m.

MIT licensed · Pre-1.0

Free and open-source under the MIT license. It's still happily pre-1.0 (v0.1.13), so the on-bucket storage format may still change as things mature.
