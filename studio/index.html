Quickstart

Dive in with two tiny steps.

Boot blowfish locally, point the official turbopuffer SDK at http://127.0.0.1:8000, and run your first vector query.

1 Start blowfish locally bash 
git clone https://github.com/endgame-labs/blowfish.git && cd blowfish
docker compose up --build --wait blowfish   # serves on 127.0.0.1:8000, auth off for local dev
2 Query it with the official turbopuffer SDK python 
# pip install turbopuffer
import os
os.environ.pop("TURBOPUFFER_REGION", None)  # a region only applies to turbopuffer's own URLs
import turbopuffer
tpuf = turbopuffer.Turbopuffer(api_key="dev", base_url="http://127.0.0.1:8000")
ns = tpuf.namespace("hello")
ns.write(upsert_rows=[{"id": 1, "vector": [0.1, 0.2], "text": "hello, blowfish"}], distance_metric="cosine_distance")
print(ns.query(rank_by=("vector", "ANN", [0.1, 0.2]), top_k=1).rows)
Works with the official Python, TypeScript, Go, Java, Ruby, and Rust SDKs — no fork or wrapper needed. Pre-1.0 Honest heads-up: blowfish is at v0.1.13, so the storage format may still change.
What's inside the shell

Small fish, surprisingly roomy architecture.

Everything you need for vector, full-text, and hybrid search — without standing up a sprawling cluster of stateful boxes.

SDK-compatible out of the box

Speaks the turbopuffer API directly. The official Python, TypeScript, Go, Java, Ruby, and Rust SDKs work unchanged — just point the base URL at blowfish.

Your bucket is the database

Stores everything in any S3-compatible bucket (AWS S3, Cloudflare R2, MinIO, or SeaweedFS) or a local directory. No other database. Servers are stateless caches — run more copies to scale out.

Vector, BM25, hybrid, and filters

Run ANN vector search, exact BM25 full-text search, hybrid rankings, and structured metadata filters in a single unified query engine.

Scales to 100M on one machine

Comfortably serves 100M documents from a single server with S3 backing, and a 10M-document workload fits neatly on a 4 GB machine.

Single Rust binary

Compiled into one fast, self-contained Rust executable. Easy to drop into Docker, CI pipelines, laptops, or air-gapped servers with zero extra services.

MIT licensed & readable

Permissively open source under the MIT license. Browse the code, learn how object-storage search ticks, file an issue, or fork it for your own adventures.
