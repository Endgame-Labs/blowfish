# blowfish 🐡

An open-source, self-hostable search engine that speaks the [turbopuffer](https://turbopuffer.com) API.
Bring any S3-compatible bucket (AWS S3, Cloudflare R2, MinIO, ...), point blowfish at it, and it does the
rest: vector, full-text, and hybrid search over namespaces kept in object storage, with existing turbopuffer
clients working unchanged.

Status: early design. See `DESIGN.md` once it exists.
