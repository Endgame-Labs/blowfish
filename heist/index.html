blowfish B L O W F I S H

An open-source, self-hostable search engine that speaks the turbopuffer API — powered by your own S3 bucket.

Vector search (ANN), BM25 full-text search, hybrid queries, and filters packed into one single Rust binary. Point the official turbopuffer SDKs at blowfish and puff it right up!

I love turbopuffer I L O V E T U R B O P U F F E R

Zero Lock-In · Same API

Let me say it plainly and happily: I love turbopuffer, I use it on many projects, large and small, and I recommend it for production.

blowfish is not a rival — it’s a friendly reef-mate for the times you want something self-hosted, offline, or right inside your own infrastructure. Because the APIs match, moving between blowfish and turbopuffer is just a base-URL change.

01

Local dev & CI without accounts

Spin up search right on your laptop or inside GitHub Actions with zero accounts, zero API tokens, and zero outbound network calls.

02

Inside your firewall, on-prem, or air-gapped

Need search where packets never leave your private VPC or data center? Drop in one Rust binary and keep everything inside your perimeter.

03

Self-host on your own bucket

Keep data residency squarely in your own AWS S3, Cloudflare R2, MinIO, or SeaweedFS bucket — or simply tinker on a local folder.

04

Learn how object-storage search works

Curious how vector ANN and BM25 indexes run directly on S3? Pop the hood, read the MIT-licensed Rust code, and hack away.

Want managed, rock-solid production search? I happily point you straight to turbopuffer.

Quickstart Q U I C K S T A R T

The Calling Card
Calling Card · 2-Step Setup

Take Your Search Local

127.0.0.1:8000

Start blowfish with Docker Compose, then point the official turbopuffer SDK straight at http://127.0.0.1:8000. Same code, zero accounts, and instant local splashdown.

STEP 01 Launch blowfish locally (Bash) 
git clone https://github.com/endgame-labs/blowfish.git && cd blowfish
docker compose up --build --wait blowfish   # serves on 127.0.0.1:8000, auth off for local dev
STEP 02 Upsert & query with the official SDK (Python) 
# pip install turbopuffer
import os
os.environ.pop("TURBOPUFFER_REGION", None)  # a region only applies to turbopuffer's own URLs
import turbopuffer
tpuf = turbopuffer.Turbopuffer(api_key="dev", base_url="http://127.0.0.1:8000")
ns = tpuf.namespace("hello")
ns.write(upsert_rows=[{"id": 1, "vector": [0.1, 0.2], "text": "hello, blowfish"}], distance_metric="cosine_distance")
print(ns.query(rank_by=("vector", "ANN", [0.1, 0.2]), top_k=1).rows)

Feature highlights W H A T ’ S I N S I D E

6 Highlights · No Bloat
01

SDK-compatible out of the box

The official turbopuffer SDKs for Python, TypeScript, Go, Java, Ruby, and Rust work unchanged. Point the base URL at blowfish and swim right in.

02

Your bucket is the database

Stores everything in any S3-compatible bucket (AWS S3, Cloudflare R2, MinIO, and SeaweedFS) or a local directory. No other database — servers are stateless caches, so run more copies to scale out.

03

Vector, BM25, hybrid, and filters

Run approximate nearest-neighbor (ANN) vector search, BM25 full-text search, hybrid queries, and metadata filters together in one tidy engine.

04

Scales to 100M on one machine

Puffs up smoothly to 100M documents on a single server, while a 10M-document workload fits comfortably on a 4 GB machine.

05

Single Rust binary

Everything ships in one self-contained Rust binary with no sidecar coordinators or cluster gossip to wrangle.

06

MIT licensed & open

Permissively licensed under MIT and meant to be read, forked, and built upon. Pre-1.0 today, so dive in and help shape what comes next.
